Financial-Anomaly-Detection-Research
🔍 Research Objective
本研究旨在探討金融跨國分行批次作業中的異常行為，透過 流程挖掘 (Process Mining) 還原交易足跡，並結合 自動化根因分析 (Automated Root Cause Analysis) 實現數位鑑識之原型系統。

🚀 Key Features
Synthetic Log Generation: 模擬具備真實金融業務邏輯的批次作業日誌。

Automated Anomaly Detection: 即時辨識網路、人為、憑證三大類系統異常。

Diagnostic Dashboard: 視覺化呈現各海外分行異常數據，並進行全行根因彙整分析。
